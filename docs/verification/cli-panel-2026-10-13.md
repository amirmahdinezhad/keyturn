## Native panel observations

- The real WebKit panel loaded Vite on port 5174 with working Tauri IPC.
  Codex and OpenCode were connected; Claude was signed out and Gemini absent.
- Add account listed the two unavailable providers. Gemini's installation
  check stayed at Install with a missing-CLI message. Claude skipped Install
  and its login check stayed at Sign in with a signed-out message.
- Codex displayed a live weekly quota percentage and reset countdown. Changing
  the percentage preference changed the live popup from remaining to used.
- OpenCode returned HTTP 403 for the stored key. The popup displayed the
  no-quota/no-active-plan message rather than showing fabricated bars.
- Refresh cadence changed from 30 to 60 seconds, survived a backend refresh
  and reopening Settings, then was restored to 30 seconds.
- Light appearance and Used wording survived the native HMR reload. Original
  Dark appearance and Left wording were restored afterward. Accent, detail
  visibility and row density remained at their initial values.
- Escape closed the setup modal. Arrow-key navigation moved from Display to
  Updates, where the running version was shown as 0.1.0.

Native automation used a temporary app wrapper around the debug binary,
forced initial window visibility and temporarily disabled hide-on-blur. This
allowed interaction checks while control moved between the editor and app.
The workaround was removed, temporary bundles deleted, and normal dev startup
restored with a hidden initial panel and the original focus-dismiss handler.

with `lsof`. Touching `CliProviders.tsx` produced a fresh HMR update and the
expected Fast Refresh invalidation/reload. The native panel continued to show

settings-load error. It was closed afterward. Dev was restarted on port 5174;
its log confirmed a finished dev build and a new debug-app PID.
