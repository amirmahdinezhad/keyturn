# Keyturn 1.1.0

## English

- Start Codex browser or device-code sign-in directly from the method picker. Cancelling returns to the picker, and failed starts can be retried there.
- Discard-confirmation buttons now have matching widths and heights.

- Codex browser and device-code sign-in now use the verified account name automatically, with email as a fallback; no account-name entry is needed.

- See each Codex account's available banked resets directly on its card, including inactive accounts.
- Account cards and Usage limits reveal their data together after matching loading placeholders, so reset balances do not appear late.
- Usage shows a compact reset card with Codex's original title, time remaining before expiration, and a smaller Use reset button. Compatible resets with the nearest expiration appear first, with a choice when several are available.
- Use a reset only after confirming the selected account and its impact inside Usage. Usage stays open and refreshes the account's balance and limits after the result.
- When an active account reaches a limit, open Use reset next to the account-switch action if a reset may be available.
- Accounts without banked resets show no reset section or empty-balance text. Failed balance checks still offer Retry; ineligible resets show only a disabled Use reset button.
- Interrupted reset attempts retain the same request ID across retries and app restarts to prevent spending another reset by accident.

## فارسی

- ورود مرورگری یا device code اکانت Codex مستقیماً با انتخاب روش شروع می‌شود؛ لغو و خطای شروع به فهرست روش‌ها برمی‌گردند.
- دکمه‌های تأیید دورریختن تغییرات عرض و ارتفاع یکسان دارند.

- ورود مرورگری و device code اکانت Codex نام را خودکار از اطلاعات تأییدشده می‌گیرد و در نبود نام از ایمیل استفاده می‌کند؛ ورود دستی نام لازم نیست.

- موجودی reset ذخیره‌شدهٔ هر اکانت Codex، از جمله اکانت‌های غیرفعال، روی کارت همان اکانت نمایش داده می‌شود.
- کارت اکانت‌ها و Usage limits پس از نمایش skeleton، اطلاعات خود را یکجا نشان می‌دهند تا موجودی reset با تأخیر به رابط اضافه نشود.
- reset در کارتی جمع‌وجور با عنوان اصلی Codex، زمان باقی‌مانده تا انقضا و دکمهٔ کوچک‌تر Use reset نمایش داده می‌شود. reset سازگار با نزدیک‌ترین انقضا در اولویت است و در صورت وجود چند گزینه می‌توانید انتخاب را تغییر دهید.
- مصرف reset فقط پس از تأیید اکانت و اثر آن داخل Usage انجام می‌شود. پنجره باز می‌ماند و موجودی و محدودیت‌ها پس از دریافت نتیجه به‌روز می‌شوند.
- هنگام رسیدن اکانت فعال به limit، در صورت وجود reset احتمالی، گزینهٔ Use reset کنار تعویض اکانت در دسترس است.
- برای اکانت بدون reset، بخش یا متن موجودی خالی نمایش داده نمی‌شود. خطای دریافت موجودی همچنان Retry دارد؛ reset غیرقابل‌مصرف فقط دکمهٔ غیرفعال دارد.
- تلاش‌های نامشخص شناسهٔ یکسان خود را پس از تلاش دوباره و اجرای مجدد برنامه حفظ می‌کنند تا reset دیگری ناخواسته مصرف نشود.
