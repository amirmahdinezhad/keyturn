## English

The first public release of Keyturn for macOS, on Apple Silicon and Intel.

- Manage AI coding accounts from a persistent menu-bar panel.
- Organize Codex and Claude accounts into workspaces, with separate appearance and usage preferences.
- Add accounts through official browser sign-in or supported credential imports.
- Monitor usage limits and reset times in the panel and menu bar.
- Switch saved Codex accounts, with confirmation before closing a busy desktop session.
- Check GitHub for updates, read the changes, download a signed package, then choose Install & relaunch.

Install: open the DMG and drag Keyturn into Applications. This release is ad-hoc signed, without Apple notarization. macOS may require allowing it in System Settings → Privacy & Security → Open Anyway after the first launch attempt.

If you used a development build pointing at the old `7SkyLab/keyturn` feed, install 1.0.0 manually once. Subsequent releases use the new GitHub updater feed.

## فارسی

اولین نسخهٔ عمومی Keyturn برای مک‌های Apple Silicon و Intel.

- مدیریت حساب‌های ابزارهای کدنویسی هوش مصنوعی از پنل نوار منو.
- دسته‌بندی حساب‌های Codex و Claude در فضای کاری، با تنظیمات مستقل ظاهر و مصرف.
- افزودن حساب با ورود رسمی مرورگر یا واردکردن فایل ورود پشتیبانی‌شده.
- نمایش سقف مصرف و زمان بازنشانی در پنل و نوار منو.
- جابه‌جایی بین حساب‌های Codex و درخواست تأیید پیش از بستن نشست فعال دسکتاپ.
- دریافت آپدیت از گیت‌هاب، مشاهدهٔ تغییرات، دانلود بستهٔ امضاشده و نصب با انتخاب Install & relaunch.

نصب: فایل DMG را باز کنید و Keyturn را به Applications بکشید. این نسخه امضای محلی دارد و Apple آن را notarize نکرده است؛ ممکن است پس از اولین تلاش اجرا، لازم باشد در System Settings → Privacy & Security گزینهٔ Open Anyway را انتخاب کنید.

اگر نسخهٔ آزمایشی با آدرس قدیمی `7SkyLab/keyturn` را دارید، نسخهٔ 1.0.0 را یک بار دستی نصب کنید. آپدیت‌های بعدی از آدرس جدید گیت‌هاب دریافت می‌شوند.
